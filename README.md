# YT NoSkip

A browser extension that prevents skipping YouTube videos while still allowing comments. Great for improving focus and attention during video learning sessions.

---

## Features

- Blocks clicks on the YouTube progress bar and scrubber.
- Prevents skipping videos using keyboard shortcuts (J, L, ArrowLeft, ArrowRight).
- Allows typing in the comment box without restriction.
- Works dynamically on YouTube pages (SPA-safe).

---

## Installation

1. Clone or download this repository:

```bash
git clone https://github.com/your-username/yt-noskip.git
```

2. Open a Chromium-based browser or Firefox and go to chrome://extensions/

3. Enable Developer mode.

4. Click Load unpacked and select the repository folder.

5. Your extension is now active!

> Note for Firefox users:  
> Due to Firefox’s handling of Manifest v3, the extension should be loaded via `about:debugging` as a temporary add-on for testing. Functionality is the same as in Chrome.
